## 🆘 Troubleshooting

### ❌ "ERROR: relation "collections" already exists"
- **This is OK!** It means migration ran before or partially
- Migration uses `IF NOT EXISTS` so it's safe to rerun
- Click RUN again, it will skip duplicate creates

### ❌ "ERROR: column "collection_id" already exists"  
- **This is OK!** Same as above - safe to rerun
- Table already has the column

### ❌ "ERROR: no results returned"
- **This is OK!** Some statements (like INSERT) don't return results
- As long as no red error message, migration succeeded

### ❌ "Authentication failed"
- Go back to: https://app.supabase.com
- Try signing in again with GitHub
- Make sure you have access to the project

### ❌ Can't find your project
- Check Supabase Dashboard → Settings
- Verify project URL matches: `apmiabucenklyfaewoun.supabase.co`
- If not found, create new project or check alternate workspace
