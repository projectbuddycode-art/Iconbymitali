## ISSUE 1: PRODUCT SAVE FAILURE - ROOT CAUSE ANALYSIS

### Error Message
```
"Could not find the 'collection' column of 'products' in the schema cache"
```

### Root Causes Identified

| Issue | Cause | Impact | Severity |
|-------|-------|--------|----------|
| **Missing Column** | `products` table has no `collection` or `collection_id` column | Data save fails | CRITICAL |
| **No Collections Table** | `collections` table does not exist | No reference data | CRITICAL |
| **No FK Constraint** | No foreign key relationship | Data integrity risk | HIGH |
| **Frontend Sends String** | ProductsTab sends collection as free text | Type mismatch with FK | HIGH |

### Database Issue Details

**Current Schema (BROKEN)**:
```
products table:
├── id, name, description
├── price, category
├── images, videos, sizes
├── NO collection column ❌
└── NO collection_id FK ❌
```

**New Schema (FIXED)**:
```
collections table (NEW):
├── id (PK)
├── name (UNIQUE)
├── description, image_url
├── display_order, is_active
└── created_at, updated_at

products table:
├── id, name, description
├── price, original_price, category
├── collection_id → collections.id (FK) ✅
├── images, videos, sizes
├── stock, featured, show_in_lookbook
└── related_products, size_chart_image_url
```

### Solution Implementation

#### 1. Supabase Client Configuration

**File**: `src/api/supabaseClient.js`

```javascript
supabase = createClient(supabaseUrl, supabaseKey, {
  auth: {
    persistSession: true,        // ✅ Keep session across reloads
    autoRefreshToken: true,      // ✅ Auto-refresh tokens
    detectSessionInUrl: true,    // ✅ Detect OAuth callbacks
    storage: window.localStorage,
    storageKey: 'icon_by_mitali_auth',
    flowType: 'pkce'
  }
});
```

**Benefits**:
- Session persists across page reloads
- Tokens automatically refreshed before expiry
- Session restored from localStorage on load
- OAuth redirects handled automatically

#### 3. useAutosaveDraft Hook

**File**: `src/hooks/useAutosaveDraft.jsx`

**Features**:
- Auto-saves form data every 5 seconds
- Stores in localStorage with 7-day expiration
- Restores draft on component mount
- Provides save state indicators
- Detects unsaved changes
- Works with any form component

**Usage Example**:
```javascript
function ProductForm() {
  const [formData, setFormData] = useState(initialData);
  const {
    hasDraft,
    saveState,
    restoreDraft,
    clearDraft
  } = useAutosaveDraft('product-form', formData);

  // Show draft restore prompt
  if (hasDraft) {
    return <RestoreDraftButton onRestore={restoreDraft} />;
  }

  return (
    <form>
      <FormFields values={formData} />
      <SaveStateIndicator state={saveState} />
    </form>
  );
}
```

**Auto-Save Behavior**:
```
User types in form
    ↓
Data changes detected
    ↓
5-second debounce timer starts
    ↓
Timer fires → saveDraftToStorage()
    ↓
localStorage updated with timestamp
    ↓
UI shows "💾 Saving..." → "✅ Saved"
    ↓
Auto-refresh after 2 seconds to "idle"
```

#### 4. beforeunload Warning

**File**: `src/hooks/useAutosaveDraft.jsx`

```javascript
export function useBeforeUnload(hasChanges, message) {
  useEffect(() => {
    if (!hasChanges) return;

    const handleBeforeUnload = (e) => {
      e.preventDefault();
      e.returnValue = message;
      return message;
    };

    window.addEventListener('beforeunload', handleBeforeUnload);
    return () => window.removeEventListener('beforeunload', handleBeforeUnload);
  }, [hasChanges, message]);
}
```

**Usage**:
```javascript
useBeforeUnload(
  formData !== initialData,
  'You have unsaved changes. Are you sure?'
);
```

## SUPPORT & TROUBLESHOOTING

### Product Save Still Fails

2. Verify FK constraint: `\d products` in psql
3. Check form sends collection_id (not collection string)

1. Check `persistSession: true` in supabaseClient.js
2. Verify localStorage enabled in browser
3. Check token expiration in browser DevTools → Storage
4. Verify network tab for auth refresh requests

### Drafts Not Restoring
1. Check browser localStorage for `draft_*` keys
2. Verify JSON parsing doesn't error
3. Check draft isn't expired (7 days)
